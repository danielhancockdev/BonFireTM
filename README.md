# 🔥 BonFireTM

BonFireTM is an Agile project management platform designed for small teams to collaborate, organise tasks, and track development progress using a Kanban workflow.

## 🚀 Purpose

BonFireTM aims to provide a lightweight alternative to large project management tools by focusing on team collaboration, task tracking, and workflow visibility.

## 🛠️ Tech Stack

### Backend
- C#
- ASP.NET Core Web API
- .NET 10
- Entity Framework Core
- SQL Server

### Frontend
- React
- TypeScript

### Development Practices
- Clean Architecture
- Agile Development
- Git/GitHub Workflow
- CI/CD
